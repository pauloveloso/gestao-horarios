
<!-- BEGIN:user-workflow-rule -->
# Workflow: Mandatory Implementation Plans
For all tasks, regardless of size or complexity, you MUST:
1. Create a clear Implementation Plan outlining what will be changed and why.
2. Request explicit user confirmation/approval before modifying any code.
3. Provide a clear explanation of the proposed actions to help the user decide.
<!-- END:user-workflow-rule -->

<!-- BEGIN:user-communication-rule -->
# Communication: Confirmation Requests
Sempre que necessitar da confirmação do usuário para executar uma ação, você DEVE enviar uma mensagem clara e concisa explicando a ação proposta e detalhando os seus efeitos esperados.
<!-- END:user-communication-rule -->
